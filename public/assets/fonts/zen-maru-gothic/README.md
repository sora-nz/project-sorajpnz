# Japanese Home hero font

Zen Maru Gothic by Yoshimichi Ohira / The Zen Maru Gothic Project Authors.
Source: https://github.com/google/fonts/tree/main/ofl/zenmarugothic
License: SIL Open Font License 1.1, included in `OFL.txt`.

The 500 and 700 WOFF2 files are Google Fonts `text=` subsets of the approved
Japanese Home heading and mission. Both together are approximately 13 KB.
They are served locally; visitors do not request fonts from Google.

Subset text:

> 海外生活に憧れや不安を抱えているあなたへ。そんな方たちの、ちょっとした支えになるものを届けたい。

If this copy changes, regenerate both subsets from the official Google Fonts
CSS API with the updated text. Do not apply these subsets to body copy or
other pages: uncovered characters intentionally fall back to the system font.
