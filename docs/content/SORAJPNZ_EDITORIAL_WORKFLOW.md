# SoraJPNZ Editorial Workflow

SoraJPNZ Notesを「日本 x ニュージーランドの判断材料」として育てるための、記事ごとの運用手順です。記事数よりも、実体験、前提、確認日、一次情報が追えることを優先します。

## 1. テーマを決める

- 実際に迷ったこと、検索したこと、計算したことから一つ選ぶ。
- 読者が読み終えた後に判断しやすくなる問いを一つに絞る。
- 「NZは良い・悪い」のような大きすぎる結論ではなく、条件を分けて扱う。
- 海や釣りは生活の背景やField Notesとして扱い、サイト全体の主軸にしすぎない。

## 2. 下書きを作る

- 最初はルートを `noindex, follow` にする。
- Blog Hubとsitemapにはまだ追加しない。
- 誰向けの記事か、何を扱わないかを短く明記する。
- 自分の経験と一般化できる情報を分けて書く。
- 空の金額、仮の個人情報、位置情報が見える写真を公開しない。

## 3. 数字と出典を確認する

- 法律、ビザ、税金、雇用、投資は助言として書かない。
- 数字には出典名、対象期間または適用日、確認日を添える。
- 可能な限りNew Zealand政府・公的機関・一次情報を使う。
- 取得時点で正しくても変わり得る数字には、再確認が必要だと明記する。
- 計算式や概算には、何を含み何を含まないかを示す。

## 4. 公開前QA

- タイトル、リード、見出しだけで内容が把握できるか確認する。
- 日本語を声に出して読み、過度に説明的・断定的な箇所を直す。
- 390px、430px、desktopで横スクロール、文字切れ、重なりを確認する。
- 目次、内部リンク、外部リンク、CTAを実際にクリックする。
- title、description、canonical、OG画像、JSON-LDを確認する。
- 写真は圧縮し、EXIF位置情報と私的情報がないことを確認する。
- 英語版がない日本語記事は、言語切替で `/en/blog` に戻す。
- TypeScript checkとproduction buildを通す。

## 5. 公開する

- `noindex` を解除する。
- Blog Hubから記事へリンクする。
- sitemapへ記事URLと正しい `lastmod` を追加する。
- 記事の公開日・更新日とJSON-LDの日付を揃える。
- Netlify Previewで最終確認してからmainへmergeする。
- Production URL、robots meta、canonical、sitemap掲載を再確認する。

## 6. Googleへ知らせる

- Google Search ConsoleのURL検査で公開URLをテストする。
- 問題がなければインデックス登録をリクエストする。
- sitemapを再送信する必要がある場合だけ再送信する。
- 数日から数週間は、インデックス状況を急いで判断しない。

## 7. 発信へつなげる

- YouTube: 背景や体験を長く話す。
- Instagram / TikTok: 一つの気づきや比較を短く切り出す。
- Facebook: NZ生活とコミュニティ文脈で共有する。
- SNS投稿から記事へ、記事からCalculatorやProjectsへ自然につなぐ。
- X / ThreadsはURLを保持するが、現在の主要導線にはしない。

## 8. 公開後に育てる

- 30日後: Search Consoleの表示回数、検索語、クリック、掲載順位を確認する。
- 90日後: 数字、制度、外部リンク、説明の分かりにくさを再確認する。
- 情報が変わったら更新日、本文、出典、JSON-LD、sitemapの `lastmod` を揃える。
- 読まれない記事は削除より先に、検索意図、タイトル、導入、内部リンクを見直す。

## 計測するもの

- Search Console: query、impressions、clicks、CTR、average position。
- GA4: landing page、engaged sessions、articleからCalculator・Projectsへの遷移。
- 問い合わせ: どの記事やツールがきっかけだったか。

## 写真素材の優先順位

今後あると役立つのは、観光写真よりも日常の判断材料が伝わる写真です。

- Aucklandのスーパー売り場や、個人情報を隠したレシート。
- バス・電車・通勤経路、街やフラットの外観。
- 車、給油、整備など移動コストが伝わる場面。
- 仕事、デスク、分析、制作の手元。
- 海や釣りは、Field Notesとして場所を特定しすぎない写真。

人物が写る素材は、本人の同意を確認してから使います。
