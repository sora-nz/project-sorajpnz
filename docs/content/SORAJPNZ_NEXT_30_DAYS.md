# 就職活動と並行する、次の30日

更新: 2026-09-08 / 運営案。顧客への送信・SNS投稿・営業は未実施。

## 優先順位

1. 就職活動、面談準備、既存プロジェクトを英語で説明できること。
2. いま編集しているTheaとの釣りVlogを一本仕上げる。
3. その一本から短尺とNotesを一つずつ作る。
4. 公開した動画・Notes・計算機への質問や反応を残す。今は受託Web制作の募集や営業を進めない。

就職後は、動画やNotesの更新頻度を落としてよい。毎日投稿、顧客のWebサイト運用、月額サポートを約束しない。週2時間程度の運営でも止まらない構成を目指す。これは作業枠の提案で、本人の稼働時間を確定したものではない。

Web制作サービス案は見送り。顧客情報の管理と納品後の運用責任を決められていないため、再検討の依頼があるまではサービスを作らない。YouTubeの紹介は「国際カップルの日常」を中心にし、釣りやスピアフィッシングはその暮らしの一部として伝える。

## 一本の動画から残すもの

| 場所 | 役割 | 今回の一本でやること |
| --- | --- | --- |
| YouTube | その日の体験を伝える | Theaとの釣りVlog。視聴者が見たい場面を先に。タイトルに釣果や場所の誇張を入れない |
| Shorts / Reels / TikTok | 一場面から見つけてもらう | 一つの場面を縦に編集し、字幕を付ける。各プラットフォームへ元ファイルで投稿 |
| Facebook | 既存の人に近況を伝える | 動画と短い説明。コミュニティへの投稿は各ルールを守る |
| Threads | 話してみたい小さな問い | 日々の気づきがあるときだけ。全部のSNSで同時に頑張らない |
| Notes | あとで読み返せる情報 | 実際に使った道具、準備、帰ってから気づいたこと。動画の要約だけにしない |
| Projects | 作って確かめる | 繰り返す問いが出たときだけツール化。動画ごとに新しい計算機は作らない |
| LinkedIn | 仕事の説明 | 問題設定、使ったデータ、制約、検証を英語で一つ説明。趣味動画を無理に業務実績に見せない |

動画の概要欄には、その動画に対応するNotesができたら直接リンクする。それまでは `/ja/blog` を使う。生活費の話が出ない釣り動画に、計算機を主CTAとして押し込まない。Notesには公開済みの動画URLと「動画で触れなかった補足」を加える。未公開動画URLや架空の埋め込みは作らない。

Theaの映り方、名前、字幕、サムネイルは本人の了解を確認する。家・車の番号・正確な釣り場・潜水ポイントは必要なく公開しない。海況、安全、魚のルールは動画の一日を一般化せず、必要な公式確認を別に行う。

## 使い回せる公開チェック

- 一言で「この動画・記事は何の記録か」が言える。
- 動画本編とタイトル・サムネイルが一致している。
- 実体験と、調べた事実を区別した。数字には期間と出典がある。
- 実際の公開URLを開き、スマホでリンクを確認した。
- PR Previewで日英切り替え、meta、sitemapの意図を確認した。
- 商品提供・報酬・アフィリエイトがある場合は関係を明示する。今回は導入しない。

## 最初に見る反応

再生数だけでなく「何を知りたくて見たか」「同じ質問が来るか」をメモする。仕事については面談でどの制作が会話になったかを残す。質問が来たことと、有料商品への需要があることは分けて考える。

新しい追跡コードは追加しない。既存のYouTube Studio / Search Consoleで本人が見られる数値と、匿名化した質問メモから始める。数値が少ないうちに小さな変動を成功・失敗と決めない。

## いま追加しないもの

有料コミュニティ、メルマガ、決済、講座、多数のPDF、毎週の運用代行、旅行予約、釣りガイド。英語の記事も自動量産しない。一本の動画と一つの検証を完了させてから増やす。
