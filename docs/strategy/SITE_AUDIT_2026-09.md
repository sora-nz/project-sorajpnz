| 高 | Servicesの対象・納品後の運用責任・顧客情報の管理体制が未確定 | 当初の販売案は本人の判断で見送り。募集・料金・サービスへのリンクを削除し、既存URLは募集していない旨の案内のみへ |

## 検証範囲

日英それぞれのHome、Blog、Links、Projects、Services、Contact、Privacy、Terms、Disclaimer、Relocation、Rent Radar、Calculatorと、日本語のAuckland生活費記事。合計25ルート。

- 全25ページを390pxで表示。h1が一つ、横スクロールなし、revealによる非表示なし。
- Home / Blog / Servicesの日英、JA Projects / Contact / Calculatorを430・768・1024・1440pxでも検査。36組み合わせで横スクロール・revealによる欠落なし。
- モバイルの実際のメニューと言語リンクでHome / Blog / Services / ProjectsをJA→EN→JAと往復。ルート・言語・メニュー閉鎖・表示を確認。
- 当初のServicesのFAQとContactへのCTAは検査後、サービス案の見送りに伴い削除。メニューのEscとフォーカス復帰は維持。
- 計算機で`0500`を入力してblur後`500`、sliderも`500`。円換算はFrankfurterの取得表示を確認し、手動100円へ変えると貯金目標$500が約¥50,000へ更新。
- TypeScript checkとproduction build成功。`scripts/check-site.mjs`で生成済み25ルートのSEO、noindex、sitemap、表示ガードを検査して成功。
- 本番フォームへのテスト送信はしていない。受信メールが届くことの最終確認は所有者による一回のテストが必要。

## 公開設定

`public/_headers`と`public/sitemap.xml`は変更していない。日英のCalculator、日英Links、英語Blogはnoindex, follow。日本語Blogと既に公開されたAuckland生活費記事はindex, followを維持。計算機をsitemapへ追加していない。

PR #1の岸釣り下書き、計算機UI・計算式・FX取得処理は変更していない。Auckland生活費記事は既存のタイトル・説明・更新日を共通参照する変更のみで、本文や数値は変更していない。

## リンク・画像・性能

- 既存のYouTube / Instagram / TikTok / Facebook / GitHub URLはHTTP 200。ログインを含むサービスの応答だけでは、投稿内容やアカウント所有者まで確認できたとは扱わない。LinkedInは自動取得に999を返したため、その経路での確認は未完了。URLは変更していない。
- 新しい追跡、保存、画像、動画の自動再生、ライブラリ、決済は追加していない。未公開動画を埋め込んでいない。
- Home背景の使用中JPEGは約118〜193KB。Auckland写真約242KB、計算機画像約77〜80KB。大きい旧PNGは約1.1〜1.6MBだが、Homeの現在の画像参照では使っていない。
- Headerの32pxマークが元画像約152KB、avatarが約169KB。サイズ別画像を作る余地がある。今回は画像を再圧縮・差し替えしていない。
- 非Homeルートで不要なHome画像preloadを削除。ビルドのJSはgzip約111KB、CSSはgzip約14KB。これはネットワーク・描画速度の実測スコアではない。
- Lighthouseは未実行。端末上の表示、DOM、ビルド容量、画像サイズによる簡易確認。LCP/CLSの実利用者データは取得していない。

## まだ残る課題

1. Web制作サービス案は採用見送り。再検討の依頼があるまでは営業・販売を進めない。運用・保守・顧客情報管理の責任は未解決。
2. 本人のサイト・計算機を受託実績に見せない。今は就職活動と、自分の動画・Notes・Projectsを優先する。
3. 現状はJavaScriptで本文を描画する構成。今回の修正は共有metaでありSSRではない。記事が増える時点で静的本文生成も検討する。
4. 存在しないURLがSPAの200応答になるsoft-404は残る。既存の転送ルールと404ページを整理する別変更が必要。
5. 共通CSSには使わなくなった過去レイアウトが残る。大きな削除はせず、使用範囲の検証と段階的整理を別途行う。
6. 新規の公開動画URLを受け取ったら、動画ごとのNotesと直接つなぐ。今はチャンネルリンクのみ。
7. Analyticsは既存設定のまま。公開前に実際の設定とPrivacy本文の一致、受信・保存期間を所有者が確認する。今回の変更で計算機入力を保存することはない。

## レビューする場所

日英のHome、Links、Contactを確認する。プライバシー窓口は個人名を表示せずメールを維持。YouTubeの説明は国際カップルの日常を中心に修正。Servicesは料金も募集導線も表示せず、直接URLで開いた場合の案内のみを残した。公開設定と計算機処理は変更していない。
